# NFS Underground: PC to Xbox / Android Car Converter (`pc2xbox`)

A lightweight, zero-dependency Python toolset to convert custom car 3D models (`GEOMETRY.BIN`) and textures (`TEXTURES.BIN`) compiled for **Need for Speed: Underground (PC)** — including models exported from **Blender** via **NFS-CarToolkit** — into the native format used by the **Original Xbox** and **Android** versions of the game.

---

## Features
* **Zero external dependencies:** Uses only standard Python 3 (`struct`, `sys`).
* **Full 3D Mesh Conversion (`pc2xbox_geo.py`):**
  * Reorders vertex attributes from PC layout (`XYZ + Normal + Color + UV`) to Xbox NV2A layout (`XYZ + Color + UV + Normal`).
  * Converts 60-byte PC material records into 64-byte Xbox material structures while preserving transparency/alpha flags, material IDs, texture IDs, and index offsets.
  * Applies proper 16-byte and 128-byte hardware buffer alignments (`0x11` padding & EA chunk alignment).
  * Preserves all custom body kits, bumpers, spoilers, interior parts, and upgrades compiled in **NFS-CarToolkit**, while borrowing collision/material tail data (`0x80034020`) from a donor Xbox/Android car file.
* **Texture Archive Conversion (`pc2xbox_tex.py`):**
  * Converts 32-byte PC texture format descriptors (`0x33310005`) into 60-byte Xbox NV2A descriptors (`DXT1` -> `0x0C`, `DXT3` -> `0x0E`, `DXT5` -> `0x0F`).
  * Updates Xbox memory pool flags (`0x00001000`), `mip0` sizes, and mipmap counts in `0x33310004`.
  * Packs raw DXT textures into valid **EA JDLZ** compressed streams required by the Xbox/Android engine.

---

## Requirements
* **Python 3.6+** (works on Windows, Linux, macOS, and Termux on Android).
* Your modded PC car files (`GEOMETRY_pc.BIN` and `TEXTURES_pc.BIN`).
* Original donor files (`GEOMETRY_android.BIN` and `TEXTURES_android.BIN`) from the target car slot in the Xbox/Android version (e.g. `FOCUS`, `CIVIC`, `SKYLINE`, `SUPRA`, etc.).

---

## Usage

### 1. Convert 3D Geometry (`GEOMETRY.BIN`)
```bash
python3 pc2xbox_geo.py <GEOMETRY_pc.BIN> <GEOMETRY_android_donor.BIN> <GEOMETRY_out.BIN>
```
**Example:**
```bash
python3 pc2xbox_geo.py FOCUS_pc_GEOMETRY.BIN FOCUS_android_GEOMETRY.BIN GEOMETRY.BIN
```

### 2. Convert Textures (`TEXTURES.BIN`)
```bash
python3 pc2xbox_tex.py <TEXTURES_pc.BIN> <TEXTURES_out.BIN> <TEXTURES_android_donor.BIN>
```
**Example:**
```bash
python3 pc2xbox_tex.py FOCUS_pc_TEXTURES.BIN TEXTURES.BIN FOCUS_android_TEXTURES.BIN
```

### 3. Install into the Game
Copy the generated `GEOMETRY.BIN` and `TEXTURES.BIN` into the corresponding car folder (e.g., `Cars/FOCUS/`) of your Xbox or Android build.

---

## Limitations & Notes
* **Supported Texture Formats:** `DXT1`, `DXT3`, and `DXT5` (standard formats generated by NFS-CarToolkit). Uncompressed `A8R8G8B8` textures require Morton Z-Order swizzling and are not yet implemented.
* **Donor Car Slot:** Always use the original Xbox/Android `GEOMETRY.BIN` of the exact base car slot your PC mod was compiled for, so collision bounds and tail material tables match properly.

# NFS Underground: Конвертер авто з PC на Xbox / Android (`pc2xbox`)

Легкий набір скриптів на чистому Python (без сторонніх бібліотек) для конвертації кастомних 3D-моделей автомобілів (`GEOMETRY.BIN`) та текстур (`TEXTURES.BIN`) із **PC-версії Need for Speed: Underground** — включно з моделями, створеними в **Blender** та скомпільованими через **NFS-CarToolkit** — у формат для **Original Xbox** та **Android**.

## Можливості
* **Без сторонніх залежностей:** працює на стандартному Python 3 (`struct`, `sys`).
* **Повна конвертація 3D-геометрії (`pc2xbox_geo.py`):**
  * Переставляє атрибути вершин із формату PC (`XYZ + Normal + Color + UV`) у формат Xbox NV2A (`XYZ + Color + UV + Normal`).
  * Перетворює 60-байтні записи матеріалів PC у 64-байтні структури Xbox зі збереженням прапорців прозорості, ID матеріалів, текстур та зміщень індексів.
  * Виконує точне 16-байтне та 128-байтне апаратне вирівнювання буферів (`0x11` padding).
  * Зберігає всі ваші кастомні обвіси, бампери, спойлери, салон та апгрейди з **NFS-CarToolkit**, підставляючи лише хвостовий блок колізій (`0x80034020`) із файлу-донора Xbox/Android.
* **Конвертація текстур (`pc2xbox_tex.py`):**
  * Перетворює 32-байтні дескриптори форматів PC (`0x33310005`) у 60-байтні дескриптори Xbox NV2A (`DXT1` -> `0x0C`, `DXT3` -> `0x0E`, `DXT5` -> `0x0F`).
  * Оновлює прапорці пулу пам'яті Xbox (`0x00001000`), розмір базового рівня `mip0` та кількість міпмапів у `0x33310004`.
  * Запаковує DXT-текстури у валідний стиснений потік **EA JDLZ**, необхідний для завантажувача текстур Xbox/Android.
* **Скрипт (pc2xbox_wheels.py) на базі стандартного модуля argparse — скрипт підтримує 3 зручні режими без сторонніх бібліотек.**

## Вимоги
* **Python 3.6+** (працює на Windows, Linux, macOS та в Termux на Android).
* Ваші модифіковані файли авто для PC (`GEOMETRY_pc.BIN` та `TEXTURES_pc.BIN`).
* Оригінальні файли-донори (`GEOMETRY_android.BIN` та `TEXTURES_android.BIN`) тієї самої базової моделі авто з версії для Xbox/Android (наприклад, `FOCUS`, `CIVIC`, `SKYLINE`, `SUPRA` тощо).

## Використання

### 1. Конвертація 3D-геометрії (`GEOMETRY.BIN`)
```bash
python3 pc2xbox_geo.py <GEOMETRY_pc.BIN> <GEOMETRY_android_donor.BIN> <GEOMETRY_out.BIN>
```
• GEOMETRY_pc.BIN — ваш створений/відредагований GEOMETRY.BIN із Windows.

• GEOMETRY_android_donor.BIN — оригінальний GEOMETRY.BIN цієї ж моделі авто з Android-версії гри (як «донор» таблиці деталей та хвоста 0x80034020).

• GEOMETRY_out.BIN — готовий файл для Xbox/Android!

**Приклад:**
```bash
python3 pc2xbox_geo.py FOCUS_pc_GEOMETRY.BIN FOCUS_android_GEOMETRY.BIN GEOMETRY.BIN
```

### 2. Конвертація текстур (`TEXTURES.BIN`)
```bash
python3 pc2xbox_tex.py <TEXTURES_pc.BIN> <TEXTURES_out.BIN> <TEXTURES_android_donor.BIN>
```
• TEXTURES_pc.BIN — ваш створений/відредагований TEXTURES.BIN із Windows.

• TEXTURES_android_donor.BIN — оригінальний TEXTURES.BIN цієї ж моделі авто з Android-версії гри (як «донор» таблиці).

**Приклад:**
```bash
python3 pc2xbox_tex.py FOCUS_pc_TEXTURES.BIN TEXTURES.BIN FOCUS_android_TEXTURES.BIN
```

### 3. Встановлення у гру
Скопіюйте згенеровані `GEOMETRY.BIN` та `TEXTURES.BIN` у папку відповідного автомобіля (наприклад, `Cars/FOCUS/`) у вашій збірці для Xbox або Android.

## Примітки
* **Підтримувані формати текстур:** `DXT1`, `DXT3` та `DXT5` (стандартні формати, які генерує NFS-CarToolkit). Нестиснені текстури `A8R8G8B8` потребують Morton Z-Order swizzle і наразі не підтримуються.
* **Вибір донора:** завжди використовуйте як донора оригінальний `GEOMETRY.BIN` саме того слоту автомобіля, під який було скомпільовано ваш PC-мод.

---

### 4. Редагування позицій колес (`GlobalB.lzc`)

1. info — перегляд поточних координат усіх 4 коліс будь-якої машини у файлі.
2. edit — ручне налаштування бази (X), вильоту (Y), висоти (Z) та радіуса (R) без потреби в GlobalB_pc.lzc (можна змінювати лише потрібні параметри, решта залишаться без змін).
3. copy — автоматичне перенесення всіх налаштувань коліс із GlobalB_pc.lzc у GlobalB_android.lzc.


Подивитися поточні координати будь-якого авто (наприклад, SKYLINE):

```bash
python3 pc2xbox_wheels.py info GlobalB.lzc SKYLINE
```

Скопіювати налаштування коліс із PC-версії GlobalB.lzc (наприклад, FOCUS):

```bash
python3 pc2xbox_wheels.py copy GlobalB_pc.lzc GlobalB_android.lzc GlobalB.lzc FOCUS
```

Позиція коліс (база, колія, висота)

* --fx - передня вісь по довжині (база вперед, X)
* --rx - задня вісь по довжині (база назад, X)
* --y - виліт коліс (ширина колії) одночасно для обох осей
* --fy - передня колія (виліт передніх коліс, Y)
* --ry - задня колія (виліт задніх коліс, Y)
* --z - кліренс авто
* --fz - висота передніх коліс по вертикалі (Z)
* --rz - висота задніх коліс по вертикалі (Z)

Ширина покришок

* --w - ширина коліс одночасно для обох осей
* --fw - ширина передніх коліс
* --rw - ширина задніх коліс

Діаметр та радіус коліс (однакові для всіх 4 коліс)

* --d - зовнішній діаметр коліс (D)
* --r - радіус коліс (R, половина діаметра)

Усі значення вказуються в метрах (наприклад, ширина 0.215 — це 215 мм, а діаметр 0.620 — це 62 см). Задавати можна лише ті параметри, які ви хочете змінити — усі інші залишаться незмінними.


Вручну змінити базу (X), виліт (Y), висоту (Z) та радіус (R):
Змінити діаметр і ширину однаково для всіх 4 коліс:

```bash
python3 pc2xbox_wheels.py edit GlobalB_android.lzc GlobalB.lzc FOCUS --fx 1.346 --rx 1.346 --y 0.80 --z 0.0975 --w 0.215 --d 0.630
```

Зробити задні колеса ширшими та більшими за діаметром (наприклад, для задньопривідного авто чи драг-конфігурації):

```bash
python3 pc2xbox_wheels.py edit GlobalB_android.lzc GlobalB.lzc FOCUS --fw 0.195 --rw 0.245 --fd 0.610 --rd 0.640
```

Ви можете задавати ширину (--w, --fw, --rw), виліт (--y, --fy, --ry), базу (--fx, --rx) та висоту (--z, --fz, --rz) окремо для передньої та задньої осей:

### Також зверніть увагу: якщо ви робите кілька правок по черзі, у другому запуску як вхідний файл потрібно передавати вже відредагований GlobalB.lzc (можна вказувати той самий файл як вхідний і вихідний), а не початковий GlobalB_android.lzc.


**Крок 1: задаємо різну передню та задню колію:**

```bash
python3 pc2xbox_wheels.py edit GlobalB_android.lzc GlobalB.lzc FOCUS --fy 0.79 --ry 0.83
```


**Крок 2: у вже зміненому GlobalB.lzc міняємо тільки ширину та діаметр (колії залишаться 0.79 і 0.83):**

```bash
python3 pc2xbox_wheels.py edit GlobalB.lzc GlobalB.lzc FOCUS --fw 0.195 --rw 0.235 --d 0.620
```
